# Chat | Nathan's AI

- Toolchain: [Vite+](https://viteplus.dev/)
- React Framework: [Tanstack Start](https://tanstack.com/start/latest)
- DB: [Convex](https://www.convex.dev/)
- Auth: [Better Auth](https://better-auth.com/docs/integrations/convex), [also](https://labs.convex.dev/better-auth/framework-guides/tanstack-start)

## Convex

Inside convex, setup the following environment variables:

```bash
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=http://localhost:3001
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
VITE_SITE_URL=http://localhost:3001
```
